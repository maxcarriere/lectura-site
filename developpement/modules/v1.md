<span class="status-badge status-dispo">En service</span>

En service sur les serveurs de Lectura depuis octobre 2026, cette génération fait tourner les démos de [LecturaLingua](https://lingua.lectura.world), [LecturaVoice](https://voice.lectura.world) et [LecturaLexique](https://lexique.lectura.world). Ni son code ni ses modèles ne sont publiés ; elle s'obtient sous licence commerciale (voir les [licences]({{ '/offres/entreprises/#licences' | relative_url }})).

Elle est organisée autour de la phonétique, pivot commun entre le texte et la voix. Des **briques** font chacune un passage (du texte à la phonétique, de la phonétique à la voix…) ; des **métiers** les assemblent pour l'utilisateur. Leur organisation est schématisée sur la page [Écosystème]({{ '/developpement/ecosysteme/#modules' | relative_url }}).

## Les briques {#briques}

| Brique | Rôle |
|--------|------|
| Transducer | Texte ⇄ phonétique (G2P, P2G), analyse grammaticale, syllabation, lecture des formules ; français et anglais |
| Lexicon | Lexique embarqué, tiré de LeXiK |
| Corrector | Correction orthographique et grammaticale |
| Translator | Traduction français ⇄ anglais |
| Synthesizer | Synthèse vocale du français, six voix |
| Decoder | Reconnaissance vocale du français |
| Aligner | Alignement d'un texte sur sa lecture |
| Subtitler | Sous-titres et vidéo à partir de l'alignement |

## Les métiers {#metiers}

| Métier | Assemblage |
|--------|------------|
| NLP-FR, NLP-EN | Transducer, Lexicon, Corrector ; Translator entre les deux langues |
| TTS | Transducer, puis Synthesizer |
| STT | Decoder, puis Transducer |
| STS | Aligner, puis Subtitler |
