## Deux générations de modules

**La première génération (v0)**, publiée en juillet 2026, est sous licence **AGPL-3.0**, sur [GitHub](https://github.com/maxcarriere/lectura-modules) et PyPI. Elle n'est plus développée ; sa documentation reste dans [Modules]({{ '/developpement/modules/' | relative_url }}).

**La génération actuelle (v1)** est en service sur nos serveurs, où elle fait tourner les démos de [LecturaLingua](https://lingua.lectura.world), [LecturaVoice](https://voice.lectura.world) et [LecturaLexique](https://lexique.lectura.world). Elle n'est pas publiée : ni son code ni ses modèles ne sont distribués. Elle s'obtient sous licence.

---

## Le parcours

1. **La démo** : vous essayez les modules en ligne, gratuitement et sans inscription.
2. **La clé d'essai** : sur demande, une clé d'accès à notre API pour l'essayer dans votre code, pour une durée limitée, en évaluation seulement (pas de production). Rien n'est installé chez vous.
3. **La licence d'évaluation** : si vous voulez intégrer les modules chez vous, ils vous sont confiés pour évaluation, sans diffusion ni usage commercial.
4. **La licence commerciale**, à l'achat : son périmètre, sa durée et son prix se fixent avec vous.

Notre API publique sert aux démos ; elle n'est pas proposée comme service. Les modules sous licence s'installent sur vos serveurs ou s'embarquent dans votre application.

## Modules concernés

La licence peut porter sur les modules de la génération actuelle :

- **Analyse du texte**, en français et en anglais : phonémisation (G2P), écriture depuis la phonétique (P2G), analyse grammaticale, syllabation
- **Correction orthographique**
- **Traduction** français ⇄ anglais
- **Synthèse vocale** du français, avec le minutage de chaque son pour le surlignage synchronisé
- **Reconnaissance vocale** du français
- **Alignement** d'un texte sur un enregistrement, sous-titres

Le module **Lexicon** (le lexique dans votre application) et les **corpus** ont leurs propres licences, présentées sur [LecturaLexique](https://lexique.lectura.world).
