Les démos de Lectura et le lexique LeXiK sont gratuits, comme le code de la première génération des modules (AGPL-3.0, sur [GitHub](https://github.com/maxcarriere/lectura-modules) ; une licence commerciale permet de l'intégrer à un produit fermé). Les usages commerciaux relèvent d'une licence, d'un produit ou d'une prestation.

---

## Services {#services}

Intégration, modèles sur mesure, préparation de données, services éditoriaux, développement, expertise IA (voir les [offres aux entreprises]({{ '/offres/pro/' | relative_url }})) : **base de 500 € par jour**. Le nombre de jours se fixe avec vous, dans un devis.

---

## Licences {#licences}

Les modèles v1 se vendent en licence pro, annuelle ou perpétuelle (2,5 fois le prix annuel), embarquement compris. Les prix sont affichés sur les sites projets : modules de langage **à partir de 499 € HT par an** sur [LecturaLingua](https://lingua.lectura.world/modeles/licences), modules de voix **à partir de 490 € HT par an** sur [LecturaVoice](https://voice.lectura.world/modeles/licences). Chaque licence v1 donne un avantage sur la [v2]({{ '/offres/pro/' | relative_url }}#v2) : 50 % de remise pour une licence annuelle, passage gratuit pour une licence perpétuelle.

Sur devis : un grand volume d'utilisation, l'option code d'entraînement et données, l'accompagnement. Ce que couvre chaque licence : page [Licences]({{ '/offres/licences/' | relative_url }}).

---

## Produits {#produits}

Les produits ont leur prix affiché sur leur site projet, où ils s'achètent directement : le module Lexicon et les corpus (syllabes, mots illustrés) sur [LecturaLexique](https://lexique.lectura.world). Les produits pour apprendre à lire auront le leur sur LecturaEducation.

---

## Demander un devis {#devis}

Décrivez votre projet à **lectura.world@gmail.com** ou par la [page de contact]({{ '/contact/' | relative_url }}) : Lectura vous propose un devis adapté.
